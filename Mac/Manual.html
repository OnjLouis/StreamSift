Find a stream

StreamSift runs on Intel and Apple Silicon Macs with macOS 13 or later. Unzip the download, then move StreamSift to Applications.

Paste a station website, a player page, a playlist address or a direct stream URL, and press Return. StreamSift follows likely listening links and checks the audio it finds. M3U, PLS and XSPF files are lists of addresses: StreamSift shows the verified streams inside them, not one result per playlist file. Several entries can be different qualities or formats of the same station.

When results are ready, focus moves to the first stream unless you moved away from the search controls. Use the arrow keys in the Streams list to read each station's name, audio format and bitrate when known. Tab to Stream details for the full address and the page or playlist it came from. If no stream is found, try the station's dedicated Listen Live or How to Listen page. Press Escape to cancel a search.

StreamSift plays a short sound when a search starts and another when it finishes, including when nothing is found. Status announcements still work when sounds are off.

To browse a streaming server, enter its main address or public status page. StreamSift checks the advertised audio in batches. Large listings may take longer, and some channels may be off air or unavailable in your region. Opening a direct stream address only checks that stream.

You can paste a TuneIn station page, such as tunein.com/radio/WNYC-FM-939-s21606/. StreamSift checks the public stream addresses for that station and skips entries labelled as a different station.

Keep the port number when entering a streaming server. For an address such as radio.example:8000, the website search tries HTTPS first and can retry HTTP if it cannot connect. Provide http:// explicitly for a server you know uses plain HTTP. An explicit HTTPS address is not changed.

You can also enter a station name or call sign, such as WNYC, in the same field and use Find Streams. For names, StreamSift matches against Radio Browser and the International Public Radio Directory (IPRD), checks the audio, and shows the source in Stream details. Use a more specific name if several stations match. The first name search may take longer while the catalogues download. Browser-assisted search requires a website address.

If the site only exposes the stream after starting its web player, try the Find with Browser button or press Command+Shift+Return. The command is also in Actions. This optional search requires Google Chrome or Microsoft Edge. It uses a temporary, muted browser session and verifies whether the media it sees can be opened independently.

Actions > Look Up in Public Directory (Command+Shift+D) checks the Radio Browser directory for the website and verifies matching stream addresses. The first lookup downloads a public catalogue, which is cached for up to a day. A channel page only matches entries for that page. To look for other stations on the same network, enter its homepage instead. Directory entries can be out of date.

Open the list in the address combo box to choose a recent search, then press Return in the field to search. StreamSift keeps the last ten successful searches, most recent first. Choose File, Clear Search History to remove them.

StreamSift reopens the last saved results without rescanning or playing anything. The filter, sort order and current row are restored when available. Listener counts are from the original search; press Command+R to refresh. Only reusable results with plain website addresses are saved: HLS rows and addresses with credentials, query strings or fragments are left out. A cancelled search or one without reusable results leaves the earlier saved list available. Choose File, New Search (Command+N) to clear the saved results. This does not remove Search History.

Use a stream

In Streams, press Command+A to select all visible results or hold Shift while moving through the list to select a range. Saving or copying includes the full selection in list order. Stream Details shows the first selected stream when more than one is selected.

In Stream Details (Command+3), use the arrow keys to choose a row. On Found on, Return searches the source page. If the source is the exact same address as the stream, Return scans the server root instead. That keeps the original scheme and port, but may find nothing if the server has no public listing. On Stream address, Return opens Save Stream Playlist for an HLS stream, or searches the address for other streams. The saved .m3u8 links to that one live stream; it does not download the broadcast. Return still plays the stream when focus is in Streams.

On Stream address, press Shift+Return to scan the server root, or choose Scan Stream Server from the context menu. Option+Return opens an address in your browser. Command+C copies the selected value without the label or extra punctuation. Use VoiceOver+Shift+M or a secondary click to open the context menu.

In Streams or Stream Details, press F4 or choose Review Text from the row's context menu. The full line opens in a read-only text field. Use the arrow keys to read it or select and copy any part. Press Escape to return to the row.

Refresh Results: Press Command+R to repeat the last search using its original address or name and search command. The selection, format filter and sort order are kept where still available. Counts are fetched once during the refresh; there is no automatic polling.

Press Command+L for Filter and Sort. Choose a format that occurs in the current results, or All formats. Sort by station name, bitrate, listener count when reported, or the original search order. Unreported values appear last in numeric orders. Listener counts are snapshots from the scan, not live counters. These choices reset when you start another search. Press Command+F to find text in the visible rows, then use Command+G or Command+Shift+G to continue forward or backward.

  • Play Stream: Select one stream and press Return to open its address in the media player chosen in Settings, without saving a playlist in your playlist folder.
  • Open Stream in Browser: Open the selected stream address in your default browser without saving a playlist. The browser decides whether it can play that format.
  • Copy Stream Addresses: Copy the selected URLs, one per line.
  • Save Playlist: Choose a file name and location for one M3U8 playlist containing all selected streams. The dialog starts in the playlist folder from Settings.
  • Open playlist folder: Open the configured folder in Finder. If it does not exist yet, StreamSift creates it.
  • Save and Open in Default Player: Save the selected streams as one playlist without asking for a name, then open it with the Mac app associated with .m3u8 files. Existing playlists are not overwritten. If macOS cannot open the file, the playlist stays saved.

To change which player Shift+Return opens, select an .m3u8 file in Finder, choose File, Get Info, select the player under Open with, and choose Change All. The Media player setting does not change this association.

Settings

Choose StreamSift, Settings or press Command+,.

In General, turn on Automatically try other search methods to try another method if the one you chose finds no playable streams or cannot finish. After the chosen method, StreamSift tries the remaining methods in website, browser, directory order and stops at the first playable result. The search can take longer and may start a temporary browser or check the public directory. This is off by default. Escape cancels the entire search.

On the General tab, turn search sounds on or off, or choose the playlist folder. The default is the StreamSift folder inside Music. The folder is created when you first open it from StreamSift or save a playlist there.

In General, use Media player to choose where Return and double-click send a stream. Automatic prefers the Mac default for .m3u8 if it is VLC or FastPlay, otherwise it looks for VLC, then FastPlay. An explicit choice uses only that player. FastPlay opens a temporary playlist, not a file in your saved playlist folder. Press F1 on the control for help.

On the Updates tab, Check for updates at startup is on by default unless you have saved a different choice. It checks GitHub for a newer version and shows a notice; it does not install anything automatically. Turn this setting off to check only when you ask.

Updates

Use StreamSift, Check for Updates to look for a newer signed version. An update installs only after you choose Install Update, and StreamSift then reopens. Your preferences and saved playlists are preserved.

Limits and privacy

StreamSift works with public HTTP and HTTPS links. It reads page and player metadata and common playlist formats, such as M3U, PLS, XSPF and ASX. It can test MP3, MP2, AAC, Ogg Opus, Ogg Vorbis, FLAC and WAV streams and recognise unencrypted live audio HLS playlists. For HLS it checks the playlist, not the individual audio segments. Some players may not support HLS. A stream may go off air later, and some URLs are temporary or work only in certain regions.

A search has request, size and time limits. Normal searches do not execute page JavaScript. Find with Browser runs scripts in a temporary session without your browsing profile, cookies or logins. Neither mode scans private network addresses or bypasses sign-in, DRM or regional restrictions.

Searches contact the sites and media addresses they check. Directory searches match against downloaded public catalogues on your computer. Your entered website address, station name or call sign is not sent to the directories. Recent successful searches are stored in StreamSift's settings on your Mac. Addresses with query parameters, fragments or credentials are not saved in history. StreamSift does not keep playback history. If you copy, export or send a URL to another app, that app may save the full address, including any parameters.

For a TuneIn station page, website search sends the station ID to TuneIn's public service. StreamSift removes recognised location and listener identifiers from addresses found through that service before checking or listing them. Some stream addresses still use provider-specific parameters that may expire.
