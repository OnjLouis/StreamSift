Find a stream

StreamSift runs on Windows 10 or 11, 64-bit. Install the .NET 10 Desktop Runtime (x64) if it is not already installed. Extract the StreamSift ZIP into its own folder and open StreamSift.exe.

Paste a station website, a player page, a playlist address or a direct stream URL, and press Enter. StreamSift follows likely listening links and checks the audio it finds. M3U, PLS and XSPF files are lists of addresses: StreamSift shows the verified streams inside them, not one result per playlist file. Several entries can be different qualities or formats of the same station.

When results are ready, focus moves to the first stream unless you moved away from the search controls. Use the arrow keys in the Streams list to read each station's name, audio format and bitrate when known. Tab to Stream details for the full address and the page or playlist it came from. If no stream is found, try the station's dedicated Listen Live or How to Listen page. Press Escape to cancel a search.

StreamSift plays a short sound when a search starts and another when it finishes, including when nothing is found. Status announcements still work when sounds are off.

If the site only exposes the stream after starting its web player, try the Find with browser button or press Ctrl+Shift+Enter. The command is also in Actions. This optional search requires Google Chrome or Microsoft Edge. It uses a temporary, muted browser session and verifies whether the media it sees can be opened independently.

Actions > Look up in public directory (Ctrl+Shift+D) checks the Radio Browser directory for the website and verifies matching stream addresses. The first lookup downloads a public catalogue, which is cached for up to a day. A channel page only matches entries for that page. To look for other stations on the same network, enter its homepage instead. Directory entries can be out of date.

Use a stream

  • Copy stream address: Paste the URL into your player's own command for opening a URL or network stream. In Foobar2000, that is File, Add Location. It is not a StreamSift setting.
  • Save playlist: Choose a file name and location for the selected stream's M3U8 playlist. The dialog starts in the playlist folder from Preferences.
  • Open playlist folder: Open the configured folder in File Explorer. If it does not exist yet, StreamSift creates it.
  • Open in default player: Save the selected stream in the playlist folder without asking for a name, then open it with the Windows app associated with .m3u8 files. Existing playlists are not overwritten. If Windows cannot open the file, the playlist stays saved.
  • Add to Foobar2000: Send the selected stream to Foobar2000 without asking it to start playback. Foobar2000 chooses the destination using its incoming-file settings. This command looks for an installed copy in Program Files. For a portable copy, open the saved playlist in Foobar2000 or use its File, Add Location command.

To change which player Shift+Enter opens, choose the default app for .m3u8 in Windows Settings, Apps, Default apps. There is no player selector in StreamSift Preferences.

Preferences

Choose Options, Preferences or press Ctrl+,.

On the General tab, turn search sounds on or off, or choose the playlist folder. The default is User\Playlists beside StreamSift. The folder is created when you first open it from StreamSift or save a playlist there.

On the Updates tab, turn on Check for updates at startup to receive a notice when a newer version is available. This is off by default and does not install anything automatically.

Updates

Use Help, Check for updates to look for a newer signed version. An update installs only after you choose Install update, and StreamSift then reopens. Your preferences and saved playlists are preserved.

Limits and privacy

StreamSift works with public HTTP and HTTPS links. It reads page and player metadata and common playlist formats, such as M3U, PLS, XSPF and ASX. It can test MP3, MP2, AAC, Ogg Opus, Ogg Vorbis, FLAC and WAV streams and recognise unencrypted live audio HLS playlists. For HLS it checks the playlist, not the individual audio segments. Some players may not support HLS. A stream may go off air later, and some URLs are temporary or work only in certain regions.

A search has request, size and time limits. Normal searches do not execute page JavaScript. Find with browser runs scripts in a temporary session without your browsing profile, cookies or logins. Neither mode scans private network addresses or bypasses sign-in, DRM or regional restrictions.

Searches contact the site and media addresses they check. The optional directory lookup downloads public Radio Browser data without sending your entered website address to the directory. The app does not save search or playback history. If you copy, export or send a URL to another app, that app may save the full address, including any parameters.
