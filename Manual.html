Find streams and files

StreamSift runs on Windows 10 or 11, 64-bit. Install the .NET 10 Desktop Runtime (x64) if it is not already installed. Extract the StreamSift ZIP into its own folder and open StreamSift.exe.

Paste a station website, a player page, a playlist address or a direct stream URL, and press Enter. StreamSift follows likely listening links and checks the audio it finds. M3U, PLS and XSPF files are lists of addresses: StreamSift shows the verified streams inside them, not one result per playlist file. Several entries can be different qualities or formats of the same station.

For a recording, paste a direct public HTTPS audio file address, such as an MP3 link offered by its publisher, and use Find Streams and Files. The link must open without a redirect, query string or sign-in. A verified recording is labelled Track. Press Enter on the result to play it in the chosen player. Track addresses are left out of recent searches and restored results.

Paste a public HTTPS directory index, such as https://onj.me/media/, to list up to 512 supported audio files in that folder. StreamSift lists tracks by file extension and the player opens them when you play. Use Enter for one track, or press Ctrl+A and then Enter to play all visible tracks in order in the chosen player. Subfolders and archives are skipped. StreamSift remembers the directory address so you can run the search again.

Paste an article or any other page with a public HTTPS audio link or embedded audio. StreamSift checks the media and lists finite recordings as tracks, alongside any live streams it verifies.

To play a podcast, paste its RSS or Atom feed address, or a page that advertises the feed, such as StroongeCast. Episodes start in feed order. Paste a public Internet Archive item's page to list its audio files. You can also paste an online .torrent address if it has an HTTP or HTTPS web seed that serves its audio. Tracker-only torrents and magnet links require a separate BitTorrent client. Press Enter on a track to play it.

When results are ready, focus moves to the first result unless you moved away from the search controls. Use the arrow keys in Results to move through the list. Radio rows show the station and any available bitrate. Folder rows have columns for name, format, size and date modified. Tab to Details for the full address and the page or playlist it came from. If no stream is found, try the station's dedicated Listen Live or How to Listen page. Press Escape to cancel a search.

StreamSift plays a short sound when a search starts. The completion sound tells you whether results were found; a different sound plays when nothing is found or the search cannot finish. If automatic fallback is on, the completion sound plays only after the search ends. Cancelling does not play a completion sound. Status announcements still work when sounds are off.

To browse a streaming server, enter its main address or public status page. StreamSift checks the advertised audio in batches. Large listings may take longer, and some channels may be off air or unavailable in your region. Opening a direct stream address only checks that stream.

You can paste a TuneIn station page, such as tunein.com/radio/WNYC-FM-939-s21606/. StreamSift checks the public stream addresses for that station and skips entries labelled as a different station.

Keep the port number when entering a streaming server. For an address such as radio.example:8000, the website search tries HTTPS first and can retry HTTP if it cannot connect. Provide http:// explicitly for a server you know uses plain HTTP. An explicit HTTPS address is not changed.

Enter a station name or call sign, such as WNYC, and use Find Streams and Files. If the name matches a recent successful website search, StreamSift checks that site again. Otherwise it looks in Radio Browser and the International Public Radio Directory (IPRD), verifies the audio, and shows the source in Details. If those sources yield no playable match, StreamSift also checks the Xiph Icecast directory. A bare .mp3 name is a station-name hint, not a requirement for MP3 audio. If the directories yield no result, try the station’s website address. The first directory search may take longer while the catalogues download. Browser-assisted search requires a website address.

Some streaming servers offer an alternate address for media players. When StreamSift verifies that the alternate carries the same live MP3 station at the same bitrate, it can show that address instead of listing both versions.

The Look up in radio directory button (Ctrl+Shift+D) checks the Radio Browser directory for the website and verifies matching stream addresses. The command is also in Actions. The first lookup downloads a public catalogue, which is cached for up to a day. A channel page only matches entries for that page. To look for other stations on the same network, enter its homepage instead. Directory entries can be out of date.

If the site only exposes the stream after starting its web player, choose Actions > Find with browser or press Ctrl+Shift+Enter. This optional search requires Google Chrome or Microsoft Edge. It uses a temporary, muted browser session and verifies whether the media it sees can be opened independently.

Press Alt+Down Arrow in the search field to open recent searches. Choose an entry, then press Enter in the field to search. StreamSift keeps the last ten successful searches, most recent first. Choose File, Clear search history to remove them.

StreamSift reopens the last saved results without rescanning or playing anything. The filter, sort order and current row are restored when available. Listener counts are from the original search; press F5 to refresh. Only reusable results with plain website addresses are saved: HLS rows and addresses with credentials, query strings or fragments are left out. A cancelled search or one without reusable results leaves the earlier saved list available. Choose File, New Search (Ctrl+N) to clear the saved results. This does not remove Search History.

Use search results

Refresh results: Press F5 to repeat the last search using its original address or name and search command. The selection, format filter and sort order are kept where still available. Counts are fetched once during the refresh; there is no automatic polling.

Press Ctrl+L for Filter and sort. Choose a format that occurs in the current results, or All formats. Sort by station name, bitrate, listener count when reported, or the original search order. Unreported values appear last in numeric orders. Listener counts are snapshots from the scan, not live counters. These choices reset when you start another search. Press Ctrl+F to find text in the visible rows, then use F3 or Shift+F3 to continue forward or backward.

Directory results open in filename order, ignoring case and sorting numbers naturally. Track 2 comes before Track 10. The columns are Name, Format, Size and Date modified. Press F4 to read the full row. Filter and sort also offers Listed order, track name in reverse, and both directions for date modified and file size when the directory reports them. Missing values come last. Sizes use the values as listed, which can be rounded. Select tracks after sorting to play them in that order.

When a radio stream reports a track title, Playing shows the title reported during the scan. Press F5 to check for an updated title.

Favourites and random playback

Select a track or station and use Add to Favourites in the Favourites menu or toolbar, or press Ctrl+D. The command changes to Remove from Favourites when the item is saved. Ctrl+Shift+B switches between Favourites and search results. In Favourites, Escape also returns to the search results. Use Play Random in Actions or press Ctrl+Shift+R to send a random visible entry in the current list to your chosen player.

Press Alt+I to open the Favourites menu. Use Show Toolbar in Options to show or hide the toolbar. Tab moves directly between Results and Details in either layout.

Use Export Favourites or Ctrl+Shift+E to save an M3U8 playlist. Use Import Favourites or Ctrl+Shift+I on another computer to add its entries to the existing list. The playlist keeps the names, addresses, formats and track or station type. Mobile imports require HTTPS. The import reports skipped entries.

In Results, press Ctrl+A to select all results or hold Shift while moving through the list to select a range. Saving, copying or sending to Foobar2000 includes the full selection in list order. Details shows the first selected result when more than one is selected.

In Details (Alt+D), use the arrow keys to choose a row. On Found on, Enter searches the source page. If the source is the exact same address as the stream, Enter scans the server root instead. That keeps the original scheme and port, but may find nothing if the server has no public listing. On Stream address, Enter opens Save Playlist for an HLS stream, or searches the address for other streams. The saved .m3u8 links to that one live stream; it does not download the broadcast. Enter still plays the stream when focus is in Results.

On Stream address, press Shift+Enter to scan the server root, or choose Scan stream server from the context menu. Alt+Enter opens an address in your browser. Ctrl+C copies the selected value without the label or extra punctuation. Use the Application key or Shift+F10 to open the context menu.

In Results or Details, press F4 or choose Review text from the row's context menu. The full line opens in a read-only text field. Use the arrow keys to read it or select and copy any part. Press Escape to return to the row.

  • Play result: Select one result and press Enter to send its address directly to the media player chosen in Preferences, without saving a playlist. Foobar2000 handles this like opening a file from File Explorer; its incoming-file settings decide the destination, and it may replace the active playlist. To add streams without starting playback, use Add to Foobar2000 instead.
  • Open address in browser: Open the selected address in your default browser without saving a playlist. The browser decides whether it can play that format.
  • Copy addresses: Copy the selected URLs, one per line. To open an address in Foobar2000, use its File, Add Location command.
  • Save playlist: Choose a file name and location for one M3U8 playlist containing all selected items. The dialog starts in the playlist folder from Preferences.
  • Open playlist folder: Open the configured folder in File Explorer. If it does not exist yet, StreamSift creates it.
  • Save and open in default player: Save the selected items as one playlist without asking for a name, then open it with the Windows app associated with .m3u8 files. Existing playlists are not overwritten. If Windows cannot open the file, the playlist stays saved.
  • Add to Foobar2000: Send the selected items to Foobar2000 without asking it to start playback. Foobar2000 chooses the destination using its incoming-file settings. This command looks for an installed copy in Program Files. For a portable copy, open the saved playlist in Foobar2000 or use its File, Add Location command.

To change which player Shift+Enter opens, choose the default app for .m3u8 in Windows Settings, Apps, Default apps. The Media player preference does not change this Windows setting.

Preferences

Choose Options, Preferences or press Ctrl+,.

In General, turn on Automatically try other search methods to try another method if the one you chose finds no results or cannot finish. Find Streams and Files tries the website first, then the public directory, then the browser. If you choose the directory or browser yourself, it runs first and StreamSift tries the other methods in that same order. It stops at the first playable result. This is off by default. Escape cancels the entire search.

On the General tab, turn search sounds on or off, or choose the playlist folder. When sounds are enabled, the search sound plays at the start and repeats every two seconds while the search runs. The default playlist folder is User\Playlists beside StreamSift. The folder is created when you first open it from StreamSift or save a playlist there.

In General, use Media player (Alt+M) to choose where Enter and double-click send a result. Automatic uses the Windows default for .m3u8 if set, otherwise it looks in Program Files for VLC, Foobar2000 and FastPlay, in that order. If a player you picked is missing, StreamSift tells you which player it could not find.

Use Choose Player (Alt+Y) to select a player executable that can open .m3u8 playlists. Its name appears under Media player once you choose it. Select OK to use it only in StreamSift. The player receives a temporary playlist with the selected results in order. If you move the executable, use Choose Player again. Press F1 on either control for help.

On the Updates tab, Check for updates at startup is on by default unless you have saved a different choice. It checks GitHub for a newer version and shows a notice; it does not install anything automatically. Turn this setting off to check only when you ask.

Updates

Use Help, Check for updates to look for a newer signed version. An update installs only after you choose Install update, and StreamSift then reopens. Your preferences and saved playlists are preserved.

Use Help, Version History to read the latest published notes in a read-only dialog or open all releases in your browser.

Limits and privacy

StreamSift works with public HTTP and HTTPS links. It reads page and player metadata and common playlist formats, such as M3U, PLS, XSPF and ASX. It can test MP3, MP2, AAC, Ogg Opus, Ogg Vorbis, FLAC and WAV streams and recognise unencrypted live audio HLS playlists. For HLS it checks the playlist, not the individual audio segments. Some players may not support HLS. A stream may go off air later, and some URLs are temporary or work only in certain regions.

Website and browser searches can also find public MP4 and WebM video and unencrypted live HLS video that does not require a separate audio playlist. Press Enter to play a result. Automatic uses your default playlist app when available. StreamSift can hand it a temporary playlist without asking you to save one. The player determines whether it shows the video or plays only the audio. Successful website searches can be remembered; direct video addresses are not saved in search history or restored results. DASH and protected video are not supported.

A search has request, size and time limits. Normal searches do not execute page JavaScript. Find with browser runs scripts in a temporary session without your browsing profile, cookies or logins. Neither mode scans private network addresses or bypasses sign-in, DRM or regional restrictions.

Searches contact the sites and media addresses they check. Directory searches match against downloaded public catalogues on your computer. Your entered website address, station name or call sign is not sent to the directories. Recent successful searches are stored in the User folder beside the app. Addresses with query parameters, fragments or credentials are not saved in history. StreamSift does not keep playback history. If you copy, export or send a URL to another app, that app may save the full address, including any parameters.

For a TuneIn station page, website search sends the station ID to TuneIn's public service. StreamSift removes recognised location and listener identifiers from addresses found through that service before checking or listing them. Some stream addresses still use provider-specific parameters that may expire.
