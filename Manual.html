Find a stream

StreamSift runs on Windows 10 or 11, 64-bit. Install the .NET 10 Desktop Runtime (x64) if it is not already installed. Extract the StreamSift ZIP into its own folder and open StreamSift.exe.

Paste a station website, a player page, a playlist address or a direct stream URL, and press Enter. StreamSift follows likely listening links and checks the audio it finds. M3U, PLS and XSPF files are lists of addresses: StreamSift shows the verified streams inside them, not one result per playlist file. Several entries can be different qualities or formats of the same station.

When results are ready, focus moves to the first stream unless you moved away from the search controls. Use the arrow keys in the Streams list to read each station's name, audio format and bitrate when known. Tab to Stream details for the full address and the page or playlist it came from. If no stream is found, try the station's dedicated Listen Live or How to Listen page. Press Escape to cancel a search.

StreamSift plays a short sound when a search starts and another when it finishes, including when nothing is found. Status announcements still work when sounds are off.

To browse a streaming server, enter its main address or public status page. StreamSift checks the advertised audio in batches. Large listings may take longer, and some channels may be off air or unavailable in your region. Opening a direct stream address only checks that stream.

Keep the port number when entering a streaming server. For an address such as radio.example:8000, the website search tries HTTPS first and can retry HTTP if it cannot connect. Provide http:// explicitly for a server you know uses plain HTTP. An explicit HTTPS address is not changed.

You can also enter a station name or call sign, such as WNYC, in the same field and use Find Streams. For names, StreamSift matches against Radio Browser and the International Public Radio Directory (IPRD), checks the audio, and shows the source in Stream details. Use a more specific name if several stations match. The first name search may take longer while the catalogues download. Browser-assisted search requires a website address.

If the site only exposes the stream after starting its web player, try the Find with browser button or press Ctrl+Shift+Enter. The command is also in Actions. This optional search requires Google Chrome or Microsoft Edge. It uses a temporary, muted browser session and verifies whether the media it sees can be opened independently.

Actions > Look up in public directory (Ctrl+Shift+D) checks the Radio Browser directory for the website and verifies matching stream addresses. The first lookup downloads a public catalogue, which is cached for up to a day. A channel page only matches entries for that page. To look for other stations on the same network, enter its homepage instead. Directory entries can be out of date.

Press Alt+Down Arrow in the search field to open recent searches. Choose an entry, then press Enter in the field to search. StreamSift keeps the last ten successful searches, most recent first. Choose File, Clear search history to remove them.

Use a stream

Refresh results: Press F5 to repeat the last search using its original address or name and search command. The selection, format filter and sort order are kept where still available. Counts are fetched once during the refresh; there is no automatic polling.

Press Ctrl+L for Filter and sort. Choose a format that occurs in the current results, or All formats. Sort by station name, bitrate, listener count when reported, or the original search order. Unreported values appear last in numeric orders. Listener counts are snapshots from the scan, not live counters. These choices reset when you start another search. Press Ctrl+F to find text in the visible rows, then use F3 or Shift+F3 to continue forward or backward.

In Streams, press Ctrl+A to select all results or hold Shift while moving through the list to select a range. Saving, copying or sending to Foobar2000 includes the full selection in list order. Stream Details shows the first selected stream when more than one is selected.

In Stream Details (Alt+D), use the arrow keys to choose a row. On Stream address or Found on, press Enter to search that exact address or Alt+Enter to open it in your browser. Ctrl+C copies the selected value without the label or extra punctuation. On Stream address, use the Application key or Shift+F10 and choose Scan stream server to search the server root instead. The search keeps the original scheme and port.

  • Play stream: Select one stream and press Enter to send its address directly to the media player chosen in Preferences, without saving a playlist. Foobar2000 handles this like opening a file from File Explorer; its incoming-file settings decide the destination, and it may replace the active playlist. To add streams without starting playback, use Add to Foobar2000 instead.
  • Open stream in browser: Open the selected stream address in your default browser without saving a playlist. The browser decides whether it can play that format.
  • Copy stream addresses: Copy the selected URLs, one per line. To open an address in Foobar2000, use its File, Add Location command.
  • Save playlist: Choose a file name and location for one M3U8 playlist containing all selected streams. The dialog starts in the playlist folder from Preferences.
  • Open playlist folder: Open the configured folder in File Explorer. If it does not exist yet, StreamSift creates it.
  • Save and open in default player: Save the selected streams as one playlist without asking for a name, then open it with the Windows app associated with .m3u8 files. Existing playlists are not overwritten. If Windows cannot open the file, the playlist stays saved.
  • Add to Foobar2000: Send the selected streams to Foobar2000 without asking it to start playback. Foobar2000 chooses the destination using its incoming-file settings. This command looks for an installed copy in Program Files. For a portable copy, open the saved playlist in Foobar2000 or use its File, Add Location command.

To change which player Shift+Enter opens, choose the default app for .m3u8 in Windows Settings, Apps, Default apps. The Media player preference does not change this Windows setting.

Preferences

Choose Options, Preferences or press Ctrl+,.

In General, turn on Automatically try other search methods to try another method if the one you chose finds no playable streams or cannot finish. After the chosen method, StreamSift tries the remaining methods in website, browser, directory order and stops at the first playable result. The search can take longer and may start a temporary browser or check the public directory. This is off by default. Escape cancels the entire search.

On the General tab, turn search sounds on or off, or choose the playlist folder. The default is User\Playlists beside StreamSift. The folder is created when you first open it from StreamSift or save a playlist there.

In General, use Media player (Alt+M) to choose where Enter and double-click send a stream. Automatic prefers the Windows default for .m3u8 if it is VLC, Foobar2000 or FastPlay, otherwise it looks in Program Files in that order. An explicit choice uses only that player. Set a portable copy as your Windows default for .m3u8 to use it outside Program Files. FastPlay opens a temporary playlist, not a file in your saved playlist folder. Press F1 on the control for help.

On the Updates tab, turn on Check for updates at startup to receive a notice when a newer version is available. This is off by default and does not install anything automatically.

Updates

Use Help, Check for updates to look for a newer signed version. An update installs only after you choose Install update, and StreamSift then reopens. Your preferences and saved playlists are preserved.

Limits and privacy

StreamSift works with public HTTP and HTTPS links. It reads page and player metadata and common playlist formats, such as M3U, PLS, XSPF and ASX. It can test MP3, MP2, AAC, Ogg Opus, Ogg Vorbis, FLAC and WAV streams and recognise unencrypted live audio HLS playlists. For HLS it checks the playlist, not the individual audio segments. Some players may not support HLS. A stream may go off air later, and some URLs are temporary or work only in certain regions.

A search has request, size and time limits. Normal searches do not execute page JavaScript. Find with browser runs scripts in a temporary session without your browsing profile, cookies or logins. Neither mode scans private network addresses or bypasses sign-in, DRM or regional restrictions.

Searches contact the sites and media addresses they check. Directory searches match against downloaded public catalogues on your computer. Your entered website address, station name or call sign is not sent to the directories. Recent successful searches are stored in the User folder beside the app. Addresses with query parameters, fragments or credentials are not saved in history. StreamSift does not keep playback history. If you copy, export or send a URL to another app, that app may save the full address, including any parameters.
